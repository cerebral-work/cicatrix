# Standards

Standards define the writing rules for specifications in this repository.
The primary standard is the Easy Approach to Requirements Syntax, known as EARS.

## Description

A standard in this directory defines a notation or document structure.
It defines requirements for authors and rules for automated validators.
Each standard includes a reference syntax guide and a cleanroom template.

## Source repository

Estate standards originate in cerebral-work/research.
The validator for specification structure is `cargo xtask spec-check`.
The specification catalog resides in the `specs/` directory.

## Status

The EARS standard was adopted from the research lane on 2026-10-09.
